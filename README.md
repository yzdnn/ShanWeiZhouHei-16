## **～项目概述～**

「扇尾胄黑 16」是基于「KHドット兜町16」增补简繁体汉字的16px点阵逆反差黑体，特点是横画比竖画更粗，适合在需要厚重像素风字体的场景使用。

字体名称的【胄】来自原字体名兼日本地名「【兜】町」的首字，意为头盔，【扇尾黑】来自这种字体风格「ファンテール（Fantail）」的直译，为了断句更自然而将“扇尾”提前，再加上px数16便得到「扇尾胄黑 16」。

希望这款字体能为包括但不限于像素艺术创作和游戏本地化工作的领域添砖加瓦。

虽然增补了部分繁体字，但本字体定位仍是简体字体，字形的制作和修改参考中国大陆的字形标准（G源字形）。如果需要进行繁体排版，可以考虑使用[流行點陣體16](https://github.com/scott0107000/FashionBitmap16)。

目前本字体项目尚未完工，且仍在持续更新，欢迎各位网友提出宝贵意见。
